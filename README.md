# Tic-Tac-Toe Fun

Create a responsive Tic-Tac-Toe game website.

Requirements:

1. Create a 3x3 Tic-Tac-Toe board.

2. Two players: Player X and Player O.

3. Players should take turns clicking the squares.

4. Display whose turn it is.

5. Detect when X wins, O wins, or the game is a draw.

6. Highlight the winning three squares.

7. Add a "Play Again" button that resets the board.

8. Keep score:

   - X wins

   - O wins

   - Draws

9. Add a "Reset Score" button.

10. Make the design modern, clean and attractive.

11. Add smooth hover and click animations.

12. Make it work properly on mobile and desktop.

13. Add a heading saying "Tic Tac Toe".

14. Add a short subtitle saying "Get three in a row to win!"

Use React and TypeScript.

Do not add login, database, or authentication because they are not needed.

Make the game completely functional.
